# Documentacion visual

Esta carpeta concentra las figuras usadas por los README del proyecto final.

## Contenido

- `architecture-e2e.png`: arquitectura general de la solucion.
- `forecasting-metrics.png`: metricas finales del forecasting PT/PP.
- `model-selection.png`: criterio de seleccion del modelo ganador.
- `shap-global.png`: importancia global de variables con SHAP.
- `walk-forward-summary.png`: evidencia de estabilidad temporal.
- `dashboard-executive.png`: vista ejecutiva del dashboard.
- `planning-table.png`: tabla operativa de planificacion.

## Fuente de las imagenes

Las imagenes provienen de dos fuentes del entregable final:

- la tesis final;
- la presentacion de sustentacion.

## Proposito

No son datasets ni artefactos de ejecucion. Su funcion es ayudar al lector a
entender rapidamente:

- la arquitectura;
- los resultados principales;
- y como se consumio la solucion desde negocio.
