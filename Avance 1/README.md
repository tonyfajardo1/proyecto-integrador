# Avance 1 - Inicio del Proyecto Integrador CONDIMENSA

Esta carpeta corresponde a la primera etapa del proyecto integrador y muestra el punto de partida tecnico del trabajo.

En este avance se construyo la base inicial para:

- entender las fuentes de datos de **QuickBooks** y **Comercial Kronos**;
- levantar un primer entorno ETL sobre **Mage AI**;
- definir una estructura temprana de datos para analitica y dashboard;
- preparar el terreno para los avances posteriores de modelado y forecasting.

## Objetivo del avance

El proposito de `Avance 1` fue transformar una necesidad de negocio en una primera solucion tecnica observable, centrada en:

- exploracion de fuentes;
- organizacion inicial del proyecto;
- primeras pruebas de integracion y transformacion de datos;
- estructura base del entorno analitico.

## Estructura principal

### `Comercial Kronos`

Contiene materiales iniciales relacionados con la fuente comercial Kronos, usados como referencia para entender el formato y el tipo de informacion disponible.

### `Quickbooks`

Incluye materiales base de QuickBooks y archivos de apoyo usados durante la etapa inicial para revisar tablas, dumps y datos operativos necesarios para el proyecto.

### `mage_condimensa`

Contiene la primera version del entorno de trabajo en **Mage AI**, incluyendo:

- proyecto ETL inicial;
- scripts SQL para capas de datos;
- primeras transformaciones;
- dashboard base en Streamlit para consumo de informacion.

## Relacion con los siguientes avances

`Avance 1` representa la etapa de arranque del proyecto. Su evolucion continua en:

- **Avance 2**: consolidacion de ETL, experimentos y analitica intermedia;
- **Avance 3**: refinamiento metodologico del forecasting;
- **Avance Final**: version final de tesis y publicacion consolidada.

Si quieres revisar una version mas madura del proyecto, las carpetas recomendadas son:
